# Чейнджер прав доступа Linux (Access_rights)

Интерактивный Bash-скрипт для **удобного изменения прав доступа (chmod) файлов и директорий** со встроенным справочником по числовым кодам прав.

## 🚀 Возможности

* 📚 **Встроенная шпаргалка**: Подробное описание популярных числовых прав (777, 755, 700 и т.д.) прямо в консоли.
* 🛠️ **Интерактивный режим**: Пошаговый ввод пути к файлу и желаемых прав.
* 🔍 **Валидация**: Автоматическая проверка существования файла перед изменением прав.
* 📊 **Обратная связь**: Выводит результат выполнения команды `ls -l` сразу после смены прав.

## 🛠️ Требования

* Любая Unix-подобная операционная система (Linux, macOS, WSL).
* Интерпретатор командной строки **Bash**.


## 📖 Как пользоваться

После запуска вы попадете в основное меню. Доступны три команды:

* `help` — выводит подробную таблицу-шпаргалку по правам доступа (какие коды безопасны, а какие лучше не использовать).
* `request` — запускает процесс изменения прав. Скрипт попросит ввести имя/путь к файлу, а затем цифровой код (например, `755`).
* `exit` — завершает работу скрипта.

## 📋 Справочник по правам доступа

| Код | Права (Владелец) | Права (Группа/Мир) | Буквенный вид | Описание |
| :--- | :--- | :--- | :--- | :--- |
| **777** | Полные (rwx) | Полные (rwx) | `rwxrwxrwx` | Абсолютный доступ для всех. Крайне небезопасно для боевых серверов. |
| **766** | Чтение/запись (rw-) | Чтение/запись (rw-) | `rwxr--w--w` | Все могут править, но запустить скрипт может только владелец. |
| **755** | Чтение/запуск (r-x) | Чтение/запуск (r-x) | `rwxr-xr-x` | Стандарт для сайтов и скриптов. Владелец меняет код, остальные исполняют. |
| **744** | Только чтение (r--) | Только чтение (r--) | `rwxr--r--` | Просмотр без запуска. Другие могут только посмотреть исходный код. |
| **775** | Полные (rwx) | Чтение/запуск (r-x) | `rwxrwxr-x` | Командная разработка. Коллеги из группы могут кодить, остальные — только запускать. |
| **770** | Полные (rwx) | Доступа нет (---) | `rwxrwx---` | Приватный проект группы. Посторонние пользователи не имеют доступа. |
| **750** | Чтение/запуск (r-x) | Доступа нет (---) | `rwxr-x---` | Контроль группы. Коллеги могут использовать файлы, чужие — изолированы. |
| **700** | Доступа нет (---) | Доступа нет (---) | `rwx------` | Максимальная приватность. Идеально для личных скриптов автоматизации. |

## ⚠️ Дисклеймер
Будьте осторожны при выставлении прав `777` на боевых серверах. Пользуйтесь встроенной справкой `help` для выбора безопасного режима.
